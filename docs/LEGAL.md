This repository and its release packages contain **no** game executables, game
assemblies, art, audio, data files, save files or other game content. It also

Unity reference assemblies used for compilation are not distributed: the build
instructions tell you to point the build at your own installation.

## What this project does not do

- No DRM circumvention, licence bypass, entitlement patching or account
  manipulation.
- No credential, token or key capture, and no collection of personal data.
- No telemetry, analytics or network transmission. The GUI and the injected shim
  communicate only through files in your own `%LOCALAPPDATA%` folder.
- No persistence: no services, drivers, scheduled tasks or start-up entries.
- No modification of unrelated files or system settings.

in any multiplayer, competitive, or shared-save context, and do not redistribute
game content.
